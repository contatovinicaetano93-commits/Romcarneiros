# Rom Carneiros

Landing e operação de fim de ano na Praia dos Carneiros (Tamandaré — PE).

## Stack

- Next.js 16 + React 19 + Tailwind CSS
- Deploy: [rom-carneiros.vercel.app](https://rom-carneiros.vercel.app)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Identidade visual

Paleta alinhada ao Instagram `@rom.carneiros`: verde oliva, greige/cinza e bege. Hero com carousel de 6 fotos (praia + produção), logo ROM. CARNEIROS e CTA verde.
